# 🏖️ 우리들의 여름 모임

신흥역 하늘채에서 열리는 **3박 4일 가족 모임**(금~월)을 위한 안내 페이지입니다.

- **잠자리 배치** — 방 3개 + 거실, 한 팀당 한 공간
- **4일 시간표** — 금(도착) · 토(전원 17명) · 일(13명) · 월(점심 해산)
- **선생님 프로그램** — 어른들이 돌아가며 진행하는 6가지 아이 프로그램
- **준비물 체크리스트** — 브라우저에 자동 저장

## 실행

정적 페이지라 별도 빌드가 없습니다. 로컬에서 보려면:

```bash
npx serve .        # 또는 아무 정적 서버
```

`index.html` 하나로 동작합니다.

## 배포

[Vercel](https://vercel.com)에 정적 사이트로 배포됩니다. 저장소를 연결하면 `main` 푸시 시 자동 배포됩니다.
